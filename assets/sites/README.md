# Website banner assets

Place website-entry banner images in this directory.

- Recommended source size: `1920 × 1080` or larger
- Preferred formats: `.webp`, `.jpg`, or `.png`
- Keep the important subject away from the bottom-left text area
- Use a short, lowercase filename such as `bluesea-ux.webp`

Each image is referenced from the `WEBSITE_PROJECTS` list near the end of
`index.html`, for example:

```js
image: './assets/sites/bluesea-ux.webp'
```
